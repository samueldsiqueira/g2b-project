## Como Visualizar

Para visualizar o site localmente:

1. Abra o arquivo `index.html` em seu navegador web
2. Ou use um servidor web local:
   ```bash
   # Python 3
   python3 -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   
   # Node.js (com npx)
   npx serve
   ```
3. Acesse http://localhost:8000 no navegador

## Páginas Disponíveis

- **Home** (index.html) - Página inicial com apresentação da empresa
- **Sobre G2B** (sobre.html) - Informações sobre a empresa e sua fundadora
- **Soluções** (solucoes.html) - Serviços oferecidos
- **Capacitação** (capacitacao.html) - Treinamentos executivos
