## 📤 DEPLOY NA VERCEL (3 Passos)

### Opção A: Via GitHub (Mais Fácil)

1. **Criar repositório no GitHub**
   ```bash
   # No GitHub, crie um novo repositório
   # Depois execute:
   cd /home/user-387439/samuel/g2b-nextjs
   git remote add origin https://github.com/SEU-USUARIO/g2b-nextjs.git
   git branch -M main
   git push -u origin main
   ```

2. **Conectar na Vercel**
   - Acesse: https://vercel.com
   - Clique em "Add New" → "Project"
   - Importe o repositório do GitHub
   - Clique em "Deploy"

3. **Pronto!** 🎉
   - Site estará no ar em ~2 minutos
   - URL: `https://g2b-nextjs.vercel.app`

### Opção B: Via CLI

```bash
# Instalar Vercel CLI
npm i -g vercel

# Deploy
cd /home/user-387439/samuel/g2b-nextjs

# Seguir instruções na tela
```
